.. _styles:

Styles
======

Vector data need a style definition to be visualized in an individual style. This style has to be registered in Mapbender and can then be used with vector data.

You can upload styles or create new styles.

Unterstützte Stile sind:

* Mapbox Style https://docs.mapbox.com/style-spec/guides/
* SLD Styled Layer Descriptor https://www.ogc.org/standards/sld/

.. tip:: You can create your favorite style with QGIS and export is as SLD. Then you can upload it to Mapbender and use it to visualize vector data. A nice QGIS plugin for style exort is the GeoCatBridge Plugin.
