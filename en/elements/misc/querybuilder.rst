Query Builder
*************

The QueryBuilder is not included in the standard scope of Mapbender, but can be added. The QueryBuilder provides an element that can be used to display evaluations from the database. You can define SQL queries and give them a title. These are displayed in the applications as tables or in an HTML view and can be downloaded as an Excel list.

For more information visit here: https://github.com/mapbender/query-builder/blob/master/README.md
