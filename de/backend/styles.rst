Stile
=====

Vektor-Daten benötigen eine Stil-Definition (Style), um in einem individuellen Stil dargestellt zu werden. 

Dieser Stil muss in Mapbender registriert werden und kann dann Vektor-Datenquellen zugewiesen werden.

Sie können Stile hochladen oder auch Stile in mapbender erzeugen.

Supported Styles are:

* Mapbox Style https://docs.mapbox.com/style-spec/guides/
* SLD Styled Layer Descriptor https://www.ogc.org/standards/sld/

.. tip:: Sie können ihren gewünschten Stil mit QGIS erzeugen und exportieren. Anschließend kann der Stil in Mapbender geladen werden und zur Darstellung von Vektordaten verwendet werden. Das QGIS Plugin GeoCatBridge kann für das Exportieren von Stilen empfohlen werden.
